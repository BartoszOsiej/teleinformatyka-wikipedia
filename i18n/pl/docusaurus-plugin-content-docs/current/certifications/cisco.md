## 🇬🇧 CCNA — Cisco Certified Network Associate

| Detail | Info |
|--------|------|
| **Exam** | 200-301 CCNA |
| **Questions** | 100-120 |
| **Duration** | 120 minutes |
| **Passing Score** | 825/1000 |
| **Cost** | $330 USD |
| **Validity** | 3 years |
| **Prerequisites** | None |

| Domain | Weight |
|--------|--------|
| Network Fundamentals | 20% |
| Network Access | 20% |
| IP Connectivity | 25% |
| IP Services | 10% |
| Security Fundamentals | 15% |
| Automation and Programmability | 10% |

## 🇬🇧 CCNP — Cisco Certified Network Professional

### Enterprise Track

| Exam | Focus | Cost |
|------|-------|------|
| **350-401 ENCOR** | Core (routing, switching, wireless, security, automation) | $400 |
| **300-410 ENARSI** | Advanced Routing & Services | $300 |
| **300-415 ENSDWI** | SD-WAN Solutions | $300 |
| **300-420 ENSDWI** | SD-WAN Design | $300 |
| **300-425 ENWLSD** | Wireless Design | $300 |
| **300-430 ENWLSI** | Wireless Implementation | $300 |
| **300-435 ENAUTO** | Automating Enterprise Solutions | $300 |

### Requirements
- Pass ENCOR (core) + one concentration exam
- Valid CCNA or any CCIE
