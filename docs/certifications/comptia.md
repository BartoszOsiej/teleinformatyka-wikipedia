# CompTIA Certifications

Vendor-neutral IT certifications — ideal starting point for networking careers.

---

## Certification Path

```
A+ ──► Network+ ──► Security+ ──► CySA+ / PenTest+
 │        │            │
 └──► Server+    ──► Cloud+
```

---

## CompTIA A+

| Detail | Info |
|--------|------|
| **Exams** | Core 1 (220-1101), Core 2 (220-1102) |
| **Questions** | Max 90 per exam |
| **Duration** | 90 minutes |
| **Passing Score** | 675/900 (Core 1), 700/900 (Core 2) |
| **Cost** | $349 per exam |
| **Validity** | 3 years |

### Topics

**Core 1:** Hardware, networking, mobile devices, cloud/virtualization, troubleshooting

**Core 2:** OS, security, software troubleshooting, operational procedures
