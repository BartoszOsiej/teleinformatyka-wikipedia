# Cloud Certifications

Cloud platform certifications — essential for modern infrastructure roles.

---

## AWS Certifications

### Path

```
Cloud Practitioner ──► Solutions Architect ──► Professional
                          │
                          ├──► SysOps Administrator
                          ├──► Developer
                          └──► DevOps Engineer
```

| Level | Exam | Cost | Focus |
|-------|------|------|-------|
| **Foundational** | CLF-C02 | $100 | Cloud concepts |
| **Associate** | SAA-C03 | $150 | Solutions architecture |
| **Associate** | DVA-C02 | $150 | Development |
| **Associate** | SOA-C02 | $150 | SysOps |
| **Professional** | SAP-C02 | $300 | Advanced architecture |
| **Professional** | DOP-C02 | $300 | DevOps |

## Cloud Networking Concepts

| Concept | Description |
|---------|-------------|
| **VPC** | Virtual private cloud (isolated network) |
| **Subnet** | IP range within VPC |
| **Security Group** | Stateful firewall rules |
| **NACL** | Stateless subnet-level firewall |
| **NAT Gateway** | Outbound internet for private subnets |
| **Load Balancer** | Distribute traffic across instances |
| **VPN Gateway** | Connect on-premises to cloud |
| **Direct Connect / ExpressRoute** | Dedicated connection to cloud |
